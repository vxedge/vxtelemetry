# Security policy

Do not open a public issue for a security report.

Report vulnerabilities in vxtelemetry privately through GitHub's private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**
(https://github.com/vxedge/vxtelemetry/security/advisories/new).

Supported versions, response targets, and scope notes are in the vxedge organization
security policy: https://github.com/vxedge/.github/blob/main/SECURITY.md
